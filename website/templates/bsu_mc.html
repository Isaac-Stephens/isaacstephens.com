About the Rolla BSU

The Rolla BSU Minecraft Server is an unofficial community project created for students and alumni of the Baptist Student Union at Missouri S&T.

While this server is intended to serve the Rolla BSU community, it is not an official Missouri S&T or BSU service and is independently operated and maintained by myself (Isaac Stephens) and a few other current studens and alumni.

Visit the Official BSU Website

Server Rules

  1. Be respectful. Treat other players with respect. No harassment, bullying, or targeted behavior.
  2. Don't grief. Don't destroy, steal, or intentionally damage another player's builds or belongings.
  3. Keep things appropriate. Use reasonable judgment with builds, usernames, skins, signs, and chat.
  4. No cheating. Don't use hacks, exploits, or other tools that provide an unfair advantage. (Quality of life mods are accepted though! Minimaps, zoom, stuff like that.)
  5. Respect other players' space. Don't build directly on top of or interfere with another player's base without permission.
  6. Have fun. This server exists for the Rolla BSU community. Don't ruin the experience for everyone else.

How to Join

  1. Install Minecraft 26.2.
  2. Install Fabric Loader.
  3. Install the mods listed above.
  4. Launch Minecraft.
  5. Go to Multiplayer.
  6. Add the server using the address below.
